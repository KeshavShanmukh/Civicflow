# CivicFlow Feature Matrix

| Area | Implemented capability |
|---|---|
| Identity | Registration, login, logout, salted PBKDF2 password hashes, verification tokens, password reset tokens, account lock controls, session/device inventory, role and permission catalog |
| Citizen | Profile, contact/address records, location preferences, report history, notification preferences, feedback history |
| Reporting | Create/edit/cancel/view/search/filter/sort/pagination, image upload, attachments, timestamps, history, comments |
| Intelligence | Local category classifier, severity engine, priority scoring, duplicate scoring, duplicate groups, human verification and merge workflows |
| Municipal operations | Departments, staff, skills, availability, leave records, regions, policies, assignment and workload management |
| Work orders | Creation, assignment, scheduling, state transitions, work notes, evidence, event history, verification |
| SLA | Department/severity policies, deadlines, escalation levels, overdue scheduler |
| Notifications | Local in-app notification center, read/unread state, role/event preference controls |
| Geography | Latitude/longitude storage, distance calculations, clusters, hotspots, map-ready local point data, area filters |
| Analytics | Daily/weekly/monthly reporting, category/department/status metrics, worker performance, SLA metrics, snapshots and trends |
| Dashboards | Citizen, worker, supervisor, department and administrator views |
| Reporting/export | CSV, JSON and text exports generated locally |
| Search | Reports, work orders and comments with token scoring, relevance ordering, snippets and role-aware visibility |
| Audit | Authentication, report, assignment, priority, user, configuration and operational events |
| Administration | Users, roles, permissions, departments, category policies, priority configuration, SLA configuration, notification preferences, system health |
| DevOps | Requirements files, Dockerfile, Compose, local LOC counter, tests, architecture documentation and Git workflow documentation |
