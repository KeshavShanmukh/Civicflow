# Offline Intelligence

CivicFlow does not need OpenAI, Gemini, Google Maps, Mapbox or other secret-key services.

The interactive engine uses deterministic local algorithms. The repository also includes a large offline civic signal corpus and priority-rule corpus. These records are intentionally unique by stable identifiers and can be consumed by local batch enrichment/validation tooling.

The corpus is not used as filler for the interactive UI. It provides domain-specific decision inputs for offline experiments, classification enrichment and scenario validation.
